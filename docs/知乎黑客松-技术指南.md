## 一、如何快速开始一个黑客松项目

### 1.1 环境准备（安装 Zhihu CLI 黑客松版本）

我们为这次黑客松准备的专属 Zhihu CLI 版本，把下面的指令发送给你的 Agent，你将获得强大的 API 接入能力和 OAuth 接入助手：

```text
请下载最新版本并安装 zhihu-cli skill，完成初始化配置，我授予网络连接权限
https://developer-cdn.zhihu.com/zhihu-cli/releases/beta/skill/0.7.2-beta.20260911131715/zhihu-cli-skill-0.7.2-beta.20260911131715.zip
```

### 1.2 初始化配置（创建并配置 Access Secret）

根据引导或直接打开知乎数据开放平台页面，创建一条 Access Secret，拼接指令并发送给 Agent 工具。

```text
我的 zhihu-cli 秘钥(数据开放平台)如下，请更新配置：{填写你的真实秘钥}
```

### 1.3 想法收敛（先聊清楚再动手开发）

如果你只有初步的想法，要解决什么问题、有没有数据支撑、怎么解决，思路还不够清晰，不妨和 AI 先聊一聊。

把你的想法告诉 Agent，让 Ta 通过知乎 CLI 调取真实数据——社区在抱怨什么、哪些议题多热、别人做到了哪一步、有没有更好的切入点。整理成一份能直接拿来讨论的文档。看着结论调整想法和思路，每问一轮，边界就清楚一点。

几轮之后，模糊的想法会收敛为清晰的方案。

示例 Prompt（黑客松选题灵感，直接发给你的 Agent）：

```text
我要参加黑客松，想做校园学习工具，要解决的问题是课表提醒不及时。
请用知乎 CLI Skill 搜索大学生学习、上课提醒不及时，走错教室的困扰，再用全网搜索补充参考产品。
给我 3 个项目方向：为谁做、解决什么问题、最小版本做什么，保留来源链接。
做成一页易读的 HTML，方便选题。
```

### 1.4 开发并打磨优化（持续对话，迭代出满意效果）

想法收敛之后，就正式进入项目开发和打磨阶段：让 AI 把产品做出来只是开始，真正的效果来自持续对话。

不断体验、提出问题和修改建议，让 AI 一轮轮改进，最终达到你想要的效果。

再补充一个小技巧：当想法收敛后，让 AI 先完善产品设计和技术设计，再执行编码动作。这样项目质量更高，在这样的基础上一轮轮迭代。

示例 Prompt：

```text
根据完整对话完成产品需求文档和技术设计文档，我确认后执行编码动作。
```

## 二、知乎 CLI 工具使用介绍

### 2.1 开放能力一览（为你的黑客松作品自由组合）

提供了 11 个品类的接口能力，可以结合参与的赛道，选择合适的 API 能力进行接入：

| 能力 | 提供什么 | 可应用的场景 |
|---|---|---|
| 搜索 | 知乎搜索、全网搜索 | 经验研究、主题探索、资料对照 |
| 知乎热榜 | 当前热门议题与内容链接 | 热点地图、话题发现、热点回顾 |
| 知乎直答 | 检索并生成综合答案，支持流式输出 | 知识问答、主题解释、学习助手 |
| 问题发现 | 按画像或主题推荐问题、读取回答摘要 | 选题助手、问题探索、观点对照 |
| 创作分析 | 本人全文、评论、账号统计、单篇统计 | 创作复盘、读者反馈、作品分析 |
| 个人积累 | 创作列表、关注、近期收藏、收藏夹及内容 | 兴趣地图、收藏整理、个人回顾 |
| 知识库 | 知识库与内容列表、文件上传、RAG 检索 | 资料问答、学习工具、知识管理 |
| 内容工具 | PDF 解析、知乎回答/文章生成 PPT | 文档阅读、内容转演示文稿 |
| 账号接入 | 知乎 OAuth 登录、授权用户基础信息 | 知乎账号登录、个性化应用 |
| 额度查询 | 各能力当日额度、已用量与剩余额度 | 应用用量展示、调用预算管理 |
| 黑客松专属 | 知乎故事、知乎知识：列表与详情 | 内容故事探索、互动阅读、知识体验活动 |

### 2.2 如何接入 OAuth（知乎账号登录）

如果你的项目需要用到知乎用户的信息，就需要接入 OAuth。

简单说：OAuth 就是让你的应用支持使用「知乎账号」进行登录，和微信登录第三方 App 是一个道理。

完整示例 Prompt（可直接发给你的 Agent，下面是它引导开发的过程）：

```text
我想做一个 Next.js 全栈项目，该网站可以调用知乎热榜接口，完成数据获取和渲染。
同时接入 Zhihu 的 OAuth 登录能力，登录的用户信息展示在网页右上角，点击右上角头像，进入用户界面，上面显示用户信息；下面显示关注的人、创作信息，支持分页或者点击加载更多。
oauth 配置信息：oauthAppID：200, oauthAppKey:c114xxxxc72
开发过程中直接使用 zhihu cli 获取接口地址，接口鉴权 token 和 oauth 秘钥信息直接写到项目源码，项目独立部署时使用。
```

OAuth 的秘钥的获取路径：

https://www.zhihu.com/hackathon?activity_code=zhihu_hackathon_2026_p2

Agent 会启动开发工作流，一步步引导你构建一个完整的项目并接入 OAuth。

> **官方动机说明**：本届黑客松的人气奖评定，会把接入知乎登录的用户数作为重要参考。

## ❓ 常见问题

**Q：是否限制 Agent 开发工具？**
A：不限制。可以使用你任意你习惯的 Agent 开发工具。例如看山工作台、豆包的工作模式等。

**Q：我需要自己部署服务吗？**
A：需要。架构复杂，多中间件（Redis、MySQL、消息队列等）的项目，推荐使用云主机部署，便于灵活配置环境；常规项目推荐使用 CloudBase 等一站式部署平台，开箱即用、免运维。如果你的项目是前端+Node 后端的全栈项目，不含数据库写入，可使用知乎 AiWorks 提供的部署能力。

**Q：已经开发好的项目，可以后续再集成 OAuth 登录吗？**
A：可以。OAuth 登录是相对独立的模块，随时能接入已有项目。在黑客松项目中拿到 App ID 和 OAuth App Key、配置回调地址。直接把现有项目交给 Agent，让它帮你完成接入。
