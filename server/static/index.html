粘贴不出来？点这里手动添加（复制书签代码）手机安装步骤与书签代码
  1. 复制下方完整代码，再把当前网页添加为普通书签，名称设为「保存这篇文章」。
  2. 在浏览器的书签列表中编辑它，把原来的网址全部替换为代码，保留开头的 javascript:。
  3. 在同一浏览器打开知乎文章网页版，展开完整正文，再调用「保存这篇文章」书签。

iPhone Safari：在分享菜单中添加书签，进入书签列表后点「编辑」修改网址。

Chrome：从浏览器菜单添加书签，在书签列表编辑。运行时可在地址栏输入「保存这篇文章」，点选书签建议。

不同手机浏览器对脚本书签的支持有差异。如果没有反应，可以先在电脑保存，再用手机登录同一账号继续读。

当前使用的是本机预览地址。手机请打开可访问的正式站点后再安装，电脑上的 127.0.0.1 地址不能用于手机保存。
