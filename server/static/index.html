🔖 蒸馏书签 —— 把知乎文章全文送进来

收藏列表给的是摘要。想要某篇文章的全文做深度学习？用这个书签：

  1. 把它拖进书签栏（一次性，5 秒）
    🧪 蒸馏这篇文章

    拖不动？右键书签栏 →「添加页面」→ 名称随意，网址粘贴下方代码（点击可复制）

  2. 去知乎点它：打开任意知乎回答或文章 → 点书签栏里的它 → 弹窗确认"蒸馏这篇文章？"→ 点确定
  3. 回来看结果：文章全文已进入蒸馏站，列表里会亮起「✓ 已蒸馏」标记，点击可读全文
