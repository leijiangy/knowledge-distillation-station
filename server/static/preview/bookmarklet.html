🧪 书签小工具 · 演示

体验"在知乎文章页点一下，内容就被读到"的机制（当前是安全的演示版：只读取并本地展示，不发送任何数据）

第 1 步：把下面这个绿色按钮 拖动到浏览器书签栏（直接拖，不要点击）
🧪 蒸馏这篇文章
如果拖不动：也可以右键书签栏 →「添加页面」→ 名称填"蒸馏这篇文章"，地址粘贴：javascript:(function(){...})();（完整代码见下方）
第 2 步：打开任意一篇知乎回答或专栏文章（你收藏里的那些）
例：https://www.zhihu.com/answer/2075283529018222179
第 3 步：在知乎页面上，点一下书签栏里那个绿色按钮
预期效果：弹窗显示 "✓ 蒸馏器工作正常！标题：… 正文：3726 字 …"
看到具体字数 = 全文确实被读到了。这就是整个方案的核心能力。
说明：演示版不发送数据（弹窗展示完就结束）。正式版会把正文发到知识蒸馏站的后端，文章就出现在你的列表里——要不要做正式版由你决定。

书签的完整代码（供参考）

javascript:(function(){
  var el = document.querySelector('.RichContent-inner')
        || document.querySelector('.Post-RichText')
        || document.querySelector('.RichText');
  if (!el) { alert('没找到正文——请在知乎的回答或文章页面使用'); return; }
  var text = (el.innerText || '').trim();
  alert('✓ 蒸馏器工作正常！\n\n标题：' + document.title.slice(0,50)
      + '\n\n正文：' + text.length + ' 字'
      + '\n\n开头预览：\n' + text.slice(0,100) + '…');
})();
